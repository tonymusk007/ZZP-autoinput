# ZZP自动输入2.0

粘贴内容 -> 按 F9 -> 自动输出

## 功能

- 粘贴文本到输入框，按 **F9** 自动模拟键盘输出
- **自定义过滤字符**：移除不需要的字符（如横线、空格、逗号）
- **分组输出**：按分隔符拆分，逐组输出，组间可调延时
- **速度控制**：可单独设置字符间延时和组间延时
- **结束后自动按 Enter**
- **历史记录**：双击一键填充历史内容
- **窗口置顶**：不干扰其他窗口操作
- 设置自动保存

## 使用

### 启动
双击 `start.bat` 或运行 `python auto_type.py`

### 热键
| 按键 | 功能 |
|------|------|
| F9 | 开始自动输出 |
| ESC | 中断当前输出 |

### 示例

输入：`021326-255510-564055-279982-436954-787761-102521-817346`

默认设置下：
1. 粘贴到文本框
2. 把光标移到目标窗口（网页/Excel/表单）
3. 按 F9
4. 自动逐组输出，组间延时 0.3 秒

### 过滤字符

在"过滤字符"框输入想移除的字符：
- `-`：移除所有横线
- `- `：移除横线和空格
- `,.`：移除逗号和点号
